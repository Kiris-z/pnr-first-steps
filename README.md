## 打开与部署

- 双击文件夹内 `index.html`，进入 `dist/index.html`。没有构建步骤，也没有运行时第三方依赖。
- 本地预览：在本文件夹运行 `npm run dev`，访问 `http://127.0.0.1:8766`。也可直接运行 `python3 -m http.server 8766 --bind 127.0.0.1 --directory dist`。
- 静态服务器部署：将 `dist/` 作为网站根目录发布，入口为 `dist/index.html`。所有脚本、样式、图标和截图都采用相对路径，可部署到子目录。
- JavaScript 语法检查：`npm run check`。

## 教学模型范围

- 本站未连接真实 EDA 引擎或大模型服务；所有交互是浏览器内的简化教学模型。
- 面积算例固定 100 个单元、单元总面积 6,000 µm²，不含宏单元。
- 布局线长采用示意连接的曼哈顿距离；预设状态不是实际优化算法结果。
- 时钟模型：每路径单位 0.01 ns，每缓冲器固定 0.15 ns，忽略负载、转换和工艺变化。直接路径线长 335/215/215/335；分支路径线长均为 318，再加一个缓冲器。
- 时序实验假定同相时钟，无偏斜和额外不确定度，clock-to-Q 与 setup 各 0.2 ns。只演示 Setup，不替代 Hold 或多角分析。
- 拥塞使用显式的使用量/容量比例；图例只适用于该演示。
- 旧版软件截图与当前菜单可能不同；真实工具使用请以对应版本官方文档为准。

## GitHub Pages 自动部署

推送到 `main` 后，GitHub Actions 会检查全部 JavaScript 语法，将 `dist/` 发布到 GitHub Pages；也可在 Actions 中手动运行 `Deploy GitHub Pages`。Pages 发布来源设为 GitHub Actions。无需打包、安装依赖或配置密钥。

签核入口与第 1 课加入“签核检查地图”：DRC、LVS、LEC、STA、SI、密度填充、IR/EM、功耗、ERC/PERC、ESD，共 10 类可点击解释。`signoff/index.html#power/erc` 和 `#power/esd` 提供电气连接与静电保护说明；原有 12 项清单的索引和浏览器记录保持兼容。
